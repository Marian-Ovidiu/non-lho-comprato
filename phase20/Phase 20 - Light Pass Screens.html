Connected surfaces — one dialect

After-only refined targets for the six surfaces that share the same visual system as the five priority screens. Same rules: tighten rhythm, reconcile the card dialect toward editorial, fix off-palette bits, keep every flow and a11y semantic exactly as it is.

06

Quick-add sheet

The biggest dialect clash. Today it's filled gold segmented controls + heavy ring/translate preset cards + drop-shadows — a different app from the editorial entry form. The polish pulls it onto hairline borders and the canonical underline-intent pattern, keeps the sheet's one legitimate elevation (--shadow-sheet), and leaves the toast / undo behaviour wired exactly as-is.

  • Intent control — filled gold segmented → hairline-bordered group, active tab gets accent underline (matches entry form)
  • Preset tiles — ring-1 + -translate-y + bg-primary/8 → 1px line on surface, --r-card 18, quiet press only
  • Sheet — top radius --r-sheet 28, single --shadow-sheet (the one allowed elevation)
  • Header pill — workspace chip onto editorial pill style; "Aggiunta rapida" label uses mono Label
  • Unchanged — presets, undo toast, optimistic flow, all aria-pressed states

Stats — spacing & section clarity

Phase 14 collapsed the secondary StatTrio into <details> "Dettagli del periodo" — that stays collapsed. The polish gives the disclosure a real affordance, evens section padding, and aligns the chart columns + category bars on one rhythm.

  • Disclosure — "Dettagli del periodo" gets a clear chevron row + hairline, stays collapsed by default (Phase 14)

Monthly report — narrative first

Phase 14 made the narrative primary and demoted the numeric header into "Riepilogo del mese" (collapsed). The polish honours that: a generous serif lede up top with a comfortable measure, the numeric StatTrio tucked in the disclosure, even section rhythm.

11

Empty states — one template

Empty states are scattered today. One template everywhere: mono label, a serif line that carries warmth, a muted one-liner, and a single outline CTA — on generous vertical rhythm. No illustrations, in keeping with the editorial restraint.

  • Structure — Label · serif headline · muted description · single cta-outline
  • Rhythm — centered, ~64px vertical breathing, max ~28em measure
  • Tone — copy stays honest & specific (no generic "Nessun dato")
  • Reuse — same component for dashboard / entries / stats / goals empties
